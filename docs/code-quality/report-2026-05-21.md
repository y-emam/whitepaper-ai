4. **Sanitise DB error responses** in `apps/web/app/api/papers/route.ts`, `apps/web/app/api/papers/[slug]/route.ts`, and `apps/web/app/error.tsx`.
5. **Validate `slug`** in `/api/papers/[slug]` against `/^[a-z0-9-]{1,80}$/`; return 400 on mismatch.
6. **Lock down ingestion** in `packages/ingestion/src/scrape.ts` + `ingest.ts`: host allow-list, `Content-Type` re-check, max-bytes cap.
7. **Add integration tests for `/api/ask` and `/api/papers/*`** before the Next 15 upgrade so regressions are visible.
8. **Audit `console.error` call sites** in `apps/web/app/api/ask/route.ts` and `packages/shared/src/embed.ts`; redact bodies + auth headers.
